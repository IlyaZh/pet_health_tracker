# ArchieHealthTracker Documentation

Welcome to the documentation for **ArchieHealthTracker**, a comprehensive health tracking system for pets (specifically dog Archie) with Telegram bot integration.

## Key Features
- **Symptom Tracking**: Log and monitor health symptoms.
- **Weight Management**: Keep track of pet weight over time.
- **Hygiene Logs**: Record hygiene-related events.
- **Medical Events**: Store information about vet visits and medications.
- **Telegram Integration**: Easy logging and notifications via Telegram.
- **Reporting**: Generate PDF and Telegram reports.
